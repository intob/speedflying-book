# Speedflying book

This book is titled "A Guide to Speedflying Safely". The goal of this resource is to provide relavant information to help pilots improve their speedflying.

This book is intended to provide useful information for both inexperienced and expert pilots. There should be clarification when certain advice is only suitable for expert pilots.

Contributions are very welcome. Issues and changes can be discussed on Discord (link in site's navigation). Issues and pull requests are also welcome here on GitHub.
